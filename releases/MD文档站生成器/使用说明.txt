MD 文档站生成器 · 独立版说明
================================

一、这是什么
  把一份 Markdown 文档一键生成「多页 HTML 文档站」的小工具（带图形界面）。
  本版本已把 Python 与所需组件（markdown 渲染、代码高亮）全部内置，
  目标电脑【不需要安装 Python，也不需要联网】，双击即可使用。

二、怎么用
  1. 把整个文件夹拷到任意一台 Windows 电脑（Win10/11，64 位）；
  2. 双击 DocSiteTool.exe（如杀毒软件询问，选择“允许运行”）；
  3. 界面操作：
     - “源 Markdown 文件”点【浏览…】选要转换的 .md（选择后会自动填输出目录与站点标题）；
     - “输出目录”可改（默认是 md 同目录下的同名文件夹，推荐改成 xxx/html 这种）；
     - “站点标题”留空则自动取文档第一个“#”标题；
     - 点【生成站点】，下方日志出现“生成完成 ✔”后，
       【在浏览器打开】按钮会亮起，点击即在默认浏览器查看站点。

三、目录结构约定（生成的站点）
  - index.html         首页总览
  - 每模块一个 .html    正文页
  - appendix.html      附录页（如有）
  - search-index.js    站内搜索数据
  - assets/            文档里的图片等资源

四、md 标题规则（决定站点结构）
  - 第一个 “# 标题”            → 站点标题（其下正文进首页总览）
  - 后续每个 “# 一级标题”        → 分组（左侧目录的分类抽屉）
  - “## 模块标题”              → 一个独立页面
  - “### 小节”                 → 页内栏目（页顶快捷跳转 + 搜索）
  - “## 附录…”                → 独立附录页，置于目录末尾

五、常见问题
  Q: 双击没反应？
  A: 等 1~2 秒（首次启动稍慢）；仍无反应请用
     “DocSiteTool.exe --selftest 某文档.md 某输出目录” 自检，
     结果写在输出目录上级的 _selftest_result.txt。
  Q: 生成的页面打不开图片？
  A: 图片相对路径以“md 所在目录”为基准；缺失的图片会提示但不中断生成。
  Q: 换电脑后还能再生成吗？
  A: 能。本站点目录与电脑无关，随时双击 exe 重新生成。

六、重新打包（维护者用，一般用户忽略）
  在开发机双击 build_standalone.bat 即可重新产出本文件夹
  （产物在仓库根 releases\ 目录）。
