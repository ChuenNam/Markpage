Markpage · 独立版说明
================================

一、这是什么
  把一份 Markdown 文档一键生成「多页 HTML 文档站」的小工具（带图形界面）。
  本版本已把 Python 与所需组件（markdown 渲染、代码高亮）全部内置，
  目标电脑【不需要安装 Python，也不需要联网】，双击即可使用。

二、怎么用
  1. 把整个文件夹拷到任意一台 Windows 电脑（Win10/11，64 位）；
  2. 双击 Markpage.exe（如杀毒软件询问，选择“允许运行”）。
     默认用 Edge 开一个无地址栏的独立窗口；没装 Edge 时用系统默认浏览器。
  3. 点顶部【选择 Markdown 文件…】，在自带目录浏览器里选 .md；
     也可以直接把完整路径粘贴到底部输入框后回车。
     （浏览器出于安全不提供拖入文件的磁盘路径，所以拖放不作为主入口。）
  4. 选好后：左侧是结构树和 md 编辑器，中间是实时预览，右侧四个页签：
     - 构建：日志与统计；
     - 结构：逐个二级标题点选角色（模块页 / 总览 / 附录），改动写回源 md；
     - 检查：列出标题跳级、重名、图片缺失等问题，点一条跳到源行；
     - 产物：列出所有生成页面，可打开目录、在浏览器打开、打包 zip、清理。
  5. 点顶部【生成站点】（快捷键 Ctrl+Enter）即开始构建。
     “站点选项”里可改输出位置、子目录名、站点标题、总览表自动链接、
     分组独立成页、别名映射等。

三、输出目录约定
  默认输出到“当前 md 所在目录 / site”。
  “站点选项 → 生成到子目录”默认勾选，子目录名默认 site；
  取消勾选则直接输出到当前 md 所在目录。同一目录下放多份文档时请各起一个子目录名，
  否则会互相覆盖。

四、生成的站点结构
  - index.html         首页（标题、导语、全篇总览、各组/模块入口）
  - g-*.html           分组独立页（仅在开启“分组独立成页”时生成）
  - 每模块一个 .html    正文页
  - appendix.html      附录页（如有）
  - site.css / site.js 全站样式与交互（外链一次，不逐页重复）
  - search-index.js    站内搜索数据
  - assets/            文档里的图片、视频等资源

五、md 标题规则（决定站点结构）
  - 第一个 “# 标题”             → 站点标题（其下正文进首页导语区）
  - 后续每个 “# 一级标题”        → 分组
  - “## 模块标题”               → 一个独立页面
  - “### 小节”                  → 页内小节（有锚点 id，可跳转）
  - “## 标题 {.overview}”       → 首页总览节；在分组内则归该分组
  - “## 标题 {.appendix}”       → 附录页（多个附录节合成一页）
  写错后缀不会报错、只会当普通模块页，所以成稿前请跑一次“检查”。

六、目录快捷入口
  文件选择框顶部有桌面 / 文档 / 下载等快捷入口：
  - 点末尾的 “+” 把当前浏览到的目录加为入口；
  - 鼠标悬停某个入口会向右露出 “×”，点它并确认即可删除。
  配置存在 %LOCALAPPDATA%\Markpage\quick_dirs.json，可手工编辑；
  首次运行会从 Windows 注册表播种（支持 OneDrive / 组策略重定向的目录）。

七、常见问题
  Q: 双击没反应？
  A: 等 1~2 秒（首次启动稍慢）；仍无反应请用
     “Markpage.exe --selftest 某文档.md 某输出目录” 自检，
     结果写在输出目录上级的 _selftest_result.txt。
  Q: 生成的页面打不开图片？
  A: 图片相对路径以“md 所在目录”为基准；缺失的图片会提示但不中断生成。
     远程 URL 不会被拷进站点，离线打开会丢失。
  Q: 换电脑后还能再生成吗？
  A: 能。生成的站点目录与电脑无关，随时双击 exe 重新生成。

八、重新打包（维护者用，一般用户忽略）
  在开发机双击 build_standalone.bat 即可重新产出本文件夹
  （产物在仓库根 releases\ 目录）。
