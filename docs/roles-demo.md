# Markpage 角色与总览表示例

> 本文用于演示 Markpage 2026-09 起提供的两个站点选项：
> **栏目角色**（`##` 行尾 `{.overview}` / `{.appendix}`，或 GUI/CLI 栏目规则表）与
> **总览表自动链接**（首页表格中整格等于模块标题的单元格自动指向模块页）。
> 生成命令见文末。

---

## 快速总览 {.overview}

### 三个核心部件

| 部件 | 一句话职责 |
|---|---|
| `Markdown 解析` | 标题结构扫描 + python-markdown 渲染 + 代码块增强 |
| `多页排版` | 首页 / 模块页 / 附录页模板与站内导航 |
| `搜索索引` | 按 h2/h3 切节提取纯文本，生成跨页站内搜索 |

> 本表整格文本与下方模块页标题一致，勾选「总览表自动链接」后即自动变为链接。

# 核心部件

## 选型与接线总览 {.overview}

三个部件共用同一份 `doc_site_assets.py`（CSS/JS 单一事实来源）：生成器负责把 md 切成
页面，样式与交互全部由这份资产注入，保证任意文档站观感一致。

## Markdown 解析

### Description

扫描 `#`/`##`/`###` 结构建立站点模型；渲染用 python-markdown（tables/fenced_code/
codehilite/toc/attr_list 等扩展），代码块自动补行号列、语言标签与复制按钮。

## 多页排版

### Description

首页聚合总览与分组卡片；每个模块标题一个独立页面；附录节（一个或多个）汇成固定附录页。
左目录、上下页、深浅主题均为内建。

## 搜索索引

### Description

生成 `search-index.js`：页面正文按 h2/h3 锚点切节取纯文本，顶栏搜索即时过滤、跳转锚点。

# 附录类内容

## 术语速查 {.appendix}

| 术语 | 含义 |
|---|---|
| 模块页 | 一个 `##` 模块标题生成的独立 HTML 页面 |
| 栏目角色 | module（默认）/ overview（首页）/ appendix（附录页）三种归属 |
| 严格模式 | 文档中出现任一角色声明后，按角色精确归属章节 |

## 兼容与迁移 {.appendix}

旧文档（无任何角色声明）生成结果与历史版本逐字节一致：首个「附录…」标题至文末整体进附录页，
其余 `##` 均为模块页。迁移到新声明仅需在标题行尾补后缀，且随时可以只声明一部分。
